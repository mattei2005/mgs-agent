Marketing API error 31 / subcode 3858385 when creating ads – account authentication required but no pending action visible

2

Hello,

We are trying to create ads via the Meta Marketing API

The request fails with the following error:

OAuthException code: 31 error_subcode: 3858385 message: "This request requires the user to take a pending action"

Error message returned: "Veuillez authentifier votre compte – Nous pensons que quelqu’un a peut-être essayé d’accéder à votre compte sans autorisation. Pour votre protection, vous ne pourrez pas créer ni modifier de publicités tant que vous n’aurez pas authentifié votre compte dans le Gestionnaire de publicités."

Important details: • Existing ads are running normally • The issue only happens when creating ads via the Marketing API • We already completed the Data Access Renewal • No security warning or pending action appears in Ads Manager

Example request:

POST https://graph.facebook.com/v23.0/act_xxx/ads

Parameters: { "name": "Ad - Technicien de Maintenance", "adset_id": "yyy", "creative": {"creative_id": "zzz"}, "status": "PAUSED", "destination_type": "ON_AD" }

fbtrace_id: AbYxV-zI3UkMrM-Wr5sc3ZR

Could you help identify which pending authentication or security checkpoint is blocking ad creation via the API?

Thank you.

[Graph API](https://developers.facebook.com/community?category=501017390400570)
