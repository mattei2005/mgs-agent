Cadastro domínios

Cadastre e verifique os domínios dos seus links.

Informe somente o domínio. Para vários, separe por vírgulas. O cadastro não altera seu DNS.

Como configurar o DNS

No Cloudflare: DNS → Registros → Adicionar registro. Use nome @ para o domínio principal ou o prefixo para um subdomínio. Aponte o registro A para o IP informado, com proxy ligado. A origem usa SSL Full; não altere o SSL global de uma zona existente sem verificar os outros sites. HTTPS obrigatório; painel bloqueado nos domínios de tráfego.

Verificar não altera DNS. O indicador só fica verde quando DNS e HTTPS chegam a este MGS Router, não ao servidor antigo.

Rotas

Nova rota

UTMs e parâmetros recebidos são preservados. Macros {utm_source}, {utm_medium}, {utm_campaign}, {utm_term} e {utm_content} recebem os valores do link, sem duplicação. Domínio e caminho ficam fixos após o cadastro.
