Como configurar o DNS

No Cloudflare: DNS → Registros → Adicionar registro. Use nome @ para o domínio principal ou o prefixo para um subdomínio. Aponte o registro A para o IP informado, com proxy ligado. A conexão com a origem usa SSL Full; não altere o SSL global de uma zona existente sem verificar os outros sites. HTTPS obrigatório; painel administrativo bloqueado nos domínios de tráfego.
