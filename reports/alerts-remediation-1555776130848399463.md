- Detectado parser YAML ausente no venv Hermes: ruamel disponível, PyYAML ausente. Leitor tornou-se compatível com ambos.
- Detectado import de helper produtivo mascarando candidate em Python inline; resolvido pela árvore do próprio entrypoint.
- Mudança concorrente do CUSTOM_LOG DTR foi atribuída ao receipt autorizado `zeus-performance-postupdate-1555776138440343603`, REPORT `1555781798275981384`, e preservada. Um patch textual staged duplicou bloco já presente; o gate pegou o erro, corrigido antes de publicação. Python inline também foi compilado, pois bash -n sozinho não o valida.
- Consultas auxiliares tiveram erro de subcomando/NameError/AttributeError e foram corrigidas; nenhuma execução financeira decorreu dessas consultas.

Diagnóstico read-only comprovou state canônico mais novo, last_status=ok e failure_streak=0. Corrigido somente o predicado do monitor para respeitar esse heartbeat, sem reimportar nem alterar dados financeiros. Log de erro posterior, state falho/ilegível ou heartbeat vencido continuam acionáveis; espera/parcial não prova recuperação.
