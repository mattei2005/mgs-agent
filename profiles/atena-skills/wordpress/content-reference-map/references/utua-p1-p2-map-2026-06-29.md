## Pedido

```text
O REC deles é a P1.

```

Sitemap analisado:

```text
https://utua.com.br/sitemap_index.xml
```

## Regra operacional corrigida

No domínio `utua.com.br`:

- slug `*-p1/` = **REC de referência** para o nosso fluxo.
- slug `*-p2/` = **P1 de referência** para o nosso fluxo.

Exemplo:

```text
https://utua.com.br/usa-cc-indigo-credit-card-p1/  -> REC
https://utua.com.br/usa-cc-indigo-credit-card-p2/  -> P1
```
