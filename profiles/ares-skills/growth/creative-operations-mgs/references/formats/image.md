# Formato — Imagem Criativa

Use esta referência para criativos estáticos, cards, feed, stories estáticos, banners e peças de teste visual.

## Regra central

Imagem criativa precisa ter hierarquia clara, promessa legível e composição mobile-first. Não entregar mockup local simples como peça final quando GPT/OpenAI/ChatGPT estiver disponível.

## Estrutura recomendada

```text
Camada                    Função
────────────────────────  ─────────────────────────────────────────────
Hook/headline             Parar scroll e comunicar promessa.
Visual principal          Produto/pessoa/contexto que prova a oferta.
Subheadline               Especificar benefício/condição.
CTA                       Próximo passo simples.
Elemento de confiança     Quando aplicável: comparação, selo, app, ambiente real.
```

## Quando o pedido estiver vago

Antes de gerar, se houver ambiguidade relevante, responda com entendimento e prompt editável:

```text
Entendimento do pedido
──────────────────────
[Resumo]

Prompt que vou usar
───────────────────
[Prompt visual com composição, estilo, texto e CTA]

Pontos que assumi
─────────────────
- Formato: [feed/story]
- Público: [país/idioma]
- Ângulo: [benefício]
```

## Prompt-base imagem

```text
Crie um criativo estático [FORMATO/ASPECT RATIO] para [VERTICAL] em [IDIOMA/PAÍS].

Objetivo: [OBJETIVO]
Público: [PÚBLICO]
Ângulo: [ÂNGULO]
Oferta: [OFERTA]

Composição:
- Visual principal: [PESSOA/PRODUTO/CENÁRIO]
- Headline grande: “[HEADLINE]”
- Subheadline: “[SUBHEADLINE]”
- CTA: “[CTA]”
- Estilo: [UGC / financeiro limpo / automotivo / gamer]

Regras: mobile-first, alto contraste, sem logos não autorizados, sem promessas absolutas, espaço seguro para leitura.
```

## Checklist imagem

- [ ] Headline legível em mobile.
- [ ] Oferta não está ambígua.
- [ ] Visual condiz com a vertical.
- [ ] CTA claro.
- [ ] Sem logo/marca não autorizada.
- [ ] Metadata limpa.
