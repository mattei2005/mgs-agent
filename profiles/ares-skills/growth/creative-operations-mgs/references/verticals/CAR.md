# CAR — Financiamento de Veículo

Use esta referência quando o Ares receber pedidos de criativos para financiamento, compra, consórcio, simulação ou aprovação de veículo.

## Regra central

Criativo CAR não é anúncio institucional genérico. Deve parecer peça automotiva de alta conversão: vendedor/consultor, carro protagonista, cenário de loja/rua/test-drive, ritmo rápido e gatilhos financeiros claros.

## Linguagem audiovisual esperada

```text
Elemento                  Padrão CAR
────────────────────────  ─────────────────────────────────────────────
Formato                   Vertical 9:16 para Reels/Stories/TikTok/Meta.
Estilo                    UGC comercial / vendedor real / loja de carros.
Câmera                    Handheld estável, celular premium, cortes rápidos.
Cenário                   Concessionária, pátio, showroom, rua/test-drive.
Pessoa                    Vendedor/consultor/cliente realista, energia comercial.
Carro                     Protagonista; exterior + interior + detalhe aspiracional.
Texto                     Caixa alta, branco/amarelo, contorno/sombra forte.
Voz                       Natural de vendedor brasileiro, não locução institucional fria.
Ritmo                     1-3s por cena; mudança visual frequente.
```

## Arquétipos criativos

```text
Arquétipo                 Quando usar                         Ideia
────────────────────────  ──────────────────────────────────  ─────────────────────────────
Vendedor direto           Oferta forte / fundo de funil        Consultor fala para câmera ao lado do carro.
Carro protagonista        Quando o modelo/visual vende         Close exterior, interior, rodas, painel.
Cliente conquista         Quando emoção ajuda conversão        Pessoa recebe chave/entra no carro.
Objeção removida          Score baixo/sem entrada              Vendedor quebra objeção com texto grande.
Comparação                Antes/depois ou alternativas         “Não espere juntar entrada”.
Urgência local            Campanha curta                       “Condição desta semana”.
POV test-drive            Mais aspiracional                    Câmera entrando no carro/volante/rua.
```

## Estrutura recomendada para vídeo 15s

```text
Tempo      Cena                                  Função
─────────  ────────────────────────────────────  ─────────────────────────────
0-2s       Hook com vendedor + carro             Parar scroll.
2-5s       Oferta principal                      Sem entrada / parcela.
5-8s       Close do carro/interior               Provar produto e desejo.
8-11s      Objeção removida                      Score baixo / aprovação.
11-15s     CTA direto                            Toque em Saiba Mais / Simule.
```

## Gatilhos comuns

```text
Gatilho                   Cuidado
────────────────────────  ─────────────────────────────────────────────
Compre sem entrada        Evitar promessa absoluta se houver condições.
Parcelas a partir de R$X  Não errar valor/símbolo; validar frame/contact sheet.
Mesmo com score baixo     Preferir “consulte” / “pode ter opção”; evitar garantia.
Aprovação facilitada      Não prometer aprovação certa.
Sem comprovar renda       Só usar se informado/autorizado no pedido.
```

## Prompt-base CAR — vídeo referência/variação

```text
Crie um vídeo vertical 9:16 de [DURAÇÃO] segundos, estilo Reels/TikTok de concessionária automotiva brasileira, com aparência real de gravação em celular premium.

A cena deve mostrar [PESSOA/APRESENTADOR] em [CENÁRIO AUTOMOTIVO], apresentando um [CARRO: cor/modelo/categoria] como protagonista. O vídeo deve ter energia de vendedor, cortes rápidos e aparência de anúncio real de loja de veículos, não institucional.

Sequência de cenas:
1. Hook com apresentador falando para câmera ao lado do carro.
2. Close externo do carro em ângulo bonito.
3. Detalhe do interior/volante/painel.
4. Apresentador apontando para o carro ou entregando chave.
5. CTA final olhando para câmera.

Textos na tela em caixa alta, branco e amarelo com contorno preto, terço inferior:
- [HOOK]
- [GATILHO 1]
- [GATILHO 2]
- [GATILHO 3]
- [CTA]

Voz natural de vendedor brasileiro:
“[ROTEIRO DE VOZ]”

Evitar: slideshow, imagem com zoom, visual genérico, logo/marca não autorizada, prometer aprovação garantida, esconder o carro com texto.
```

## Checklist CAR antes de entregar

- [ ] Parece vídeo automotivo real, não imagem com zoom.
- [ ] Carro aparece como protagonista em múltiplas cenas.
- [ ] Há pessoa/cenário/voz coerentes com o pedido.
- [ ] Textos e valores aparecem corretos no contact sheet.
- [ ] A oferta não virou promessa absoluta indevida.
- [ ] Metadata limpa e arquivo final `.metadata-clean.*`.
