# CC — Cartão de Crédito

Use esta referência para criativos de cartão de crédito, pré-aprovação, limite, cashback, rewards, comparação e recuperação de crédito.

## Regra central

Criativo CC precisa combinar clareza financeira com segurança/compliance. O visual deve comunicar benefício rápido sem prometer aprovação garantida, limite certo ou resultado financeiro absoluto.

## Linguagem visual esperada

```text
Elemento                  Padrão CC
────────────────────────  ─────────────────────────────────────────────
Formato                   Feed 1:1, Stories/Reels 9:16, banners.
Estilo                    Financeiro direto, limpo, benefício visível.
Pessoa                    Usuário comum, família, jovem profissional, mão segurando cartão/celular.
Produto visual            Cartão genérico/mockup, app no celular, wallet, compra.
Texto                     Headline curta + benefício + CTA.
Cores                     Alto contraste; evitar visual bancário confuso sem marca aprovada.
Cuidado                   Não prometer aprovação, limite ou score garantido.
```

## Arquétipos criativos

```text
Arquétipo                 Uso                                  Ideia
────────────────────────  ───────────────────────────────────  ─────────────────────────────
Pré-aprovação             Topo/meio de funil                    “Veja opções disponíveis”.
Limite alto               Público buscando crédito              Cartão + valor/benefício sem garantia.
Score baixo               Recuperação/baixo crédito             “Mesmo com score baixo, compare opções”.
Cashback/rewards          Benefício tangível                    Compra + retorno/recompensa.
Comparação                SEO/lead qualificado                  “Compare antes de escolher”.
Urgência                  Promo/teste                           “Confira hoje”.
```

```text
Copy na peça:
Headline: “[HEADLINE]”
Subheadline: “[SUBHEADLINE]”

Estilo: social ad polido, legível em mobile, hierarquia clara, espaço seguro para texto.
```

## Checklist CC

- [ ] Sem promessa de aprovação garantida.
- [ ] Sem cartão real com dados sensíveis.
- [ ] Benefício claro em até 2 segundos.
- [ ] CTA coerente: Apply now / Saiba mais / Ver opções / Compare.
- [ ] Naming usa operação correta e ANGLE controlado quando aplicável.
- [ ] Metadata limpa.
