# GAME — Jogos, Apps e Ofertas Gamer

Use esta referência para criativos de jogos, apps, Roblox, mobile games, rewards gamer, skins, gift cards e campanhas relacionadas.

## Regra central

Criativo GAME precisa parecer nativo do ambiente gamer/mobile: rápido, visualmente energético, com prova visual do jogo/app/recompensa. Evite visual corporativo genérico.

## Linguagem visual esperada

```text
Elemento                  Padrão GAME
────────────────────────  ─────────────────────────────────────────────
Formato                   9:16 para TikTok/Reels/Shorts; 1:1 para feed.
Estilo                    Gameplay, UI, recompensa, reação, challenge.
Pessoa                    Jogador/reação/creator/POV; pode ser sem pessoa se gameplay forte.
Ritmo                     Muito rápido, cortes a cada 0.5-2s.
Texto                     Grande, curto, com stickers/setas/highlights.
Som/Voz                   Energia de creator, não narração institucional.
Cuidado                   Não usar assets protegidos/logos sem autorização; não prometer prêmio garantido.
```

## Arquétipos criativos

```text
Arquétipo                 Uso                                  Ideia
────────────────────────  ───────────────────────────────────  ─────────────────────────────
Gameplay hook             Atrair atenção                       Melhor momento do jogo nos 2s iniciais.
Reward reveal             Oferta/recompensa                    Mostra skin/moeda/gift card como desejo.
Creator reaction          Social proof                         Pessoa reagindo ao benefício/app.
Before/after              Progressão                           “Antes sem X / depois com X”.
Challenge                 TikTok/Reels                         “Você consegue passar essa fase?”
Tutorial rápido           Lead qualificado                     3 passos para começar.
```

## Prompt-base GAME

```text
Crie um criativo [IMG/VID] vertical 9:16 para campanha GAME em [IDIOMA/PAÍS]. O vídeo deve parecer nativo de TikTok/Reels, com energia gamer e cortes rápidos.

Contexto: [JOGO/APP/OFERTA]
Público: [IDADE/INTERESSE]
Objetivo: [DOWNLOAD/LEAD/REWARD/ENGAJAMENTO]

Estrutura:
1. Hook visual forte nos primeiros 2 segundos: [HOOK].
2. Mostrar gameplay/app/recompensa: [VISUAL].
3. Criar desejo ou desafio: [ÂNGULO].
4. CTA curto: [CTA].

Texto na tela: grande, curto, com setas/stickers/highlights. Não usar logos/personagens protegidos sem autorização. Não prometer recompensa garantida se depender de condição.
```

## Checklist GAME

- [ ] Parece conteúdo gamer/social, não anúncio corporativo.
- [ ] Hook aparece nos primeiros 2s.
- [ ] Gameplay/app/recompensa está claro.
- [ ] Sem uso indevido de IP protegida.
- [ ] CTA curto e mobile-first.
- [ ] Metadata limpa.
