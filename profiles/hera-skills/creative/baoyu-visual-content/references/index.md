# Baoyu Visual Content Reference Index

Detailed absorbed libraries are organized by output family:

- `references/article-illustrator/` — original article illustration workflow, prompt construction, style presets, palettes, and style-specific notes.
- `references/comic/` — original knowledge-comic workflow, storyboard/character templates, tones, layouts, art styles, and presets.
- `references/infographic/` — original infographic analysis framework, base prompt, 21 styles, and 21 layouts.
- `references/absorbed-skill-md/` — preserved original SKILL.md files for provenance.

Use the umbrella SKILL.md for the high-level workflow, then consult these directories for narrow style/layout details.
