# REPORT-INFRA — large data directories and infra-inventory order pitfall — 2026-06-19

## Context

During a long Ares Meta Ads REPORT-INFRA chain, Zeus processed many related infra reports: scripts, Hermes crons, profile-local wrappers, large audit directories, and profile skill updates. One report registered a read-only naming audit directory with 70+ files and later an apply audit with additional JSON/CSV artifacts.

## Durable lesson

For REPORT-INFRA that points to a directory rather than one small file, do not treat it as a single opaque path or regenerate the whole inventory. Use a directory-level manifest and preserve the existing inventory shape/order.

## Recommended pattern

1. Validate structured artifacts inside the directory:
   - `python3 -m json.tool` for JSON files.
   - CSV line counts with Python/csv.
   - Count expected images/assets without dumping filenames into chat.
   - Secret scan text-like files only (`.json`, `.csv`, `.txt`, `.md`), not binary images.
2. Compute a compact manifest hash:
   - For each file: `relative_path`, `size_bytes`, `sha256`.
   - Hash the joined manifest as `sha256_manifest`.
3. Register one `data_files[]` entry for the directory:
   - `path` ending in `/`.
   - `size_bytes` total.
   - `modified_at` as max mtime.
   - `sha256_manifest`.
   - `counts` with business-relevant counts, e.g. campaigns/adsets/ads/creatives/thumbnails/CSV lines.
4. Commit the actual directory artifacts if they are durable audit evidence; otherwise mark runtime-only and explain why.
5. Keep final Discord ACK canonical and short; detailed counts belong in inventory/audit/commit.

## Pitfall validated

When updating `infra-inventory.json` programmatically, it is easy to rewrite top-level key order or overwrite entries regenerated by `infra-discovery.sh`, producing huge diffs and deleting manual context like enriched cron/script metadata.

Guardrail:

```python
# Preserve existing order and merge only targeted entries.
with open('data/infra-inventory.json') as f:
    data = json.load(f)
# mutate only data['scripts'], data['data_files'], data['crons'], etc. by path/id
# do not rebuild from scratch or sort top-level keys
```

If a bad diff shows large unrelated reordering/deletions, restore the file from HEAD and reapply a surgical merge before committing:

```bash
git checkout -- data/infra-inventory.json
# re-run minimal merge update only for reported paths/ids
python3 -m json.tool data/infra-inventory.json >/dev/null
git diff -- data/infra-inventory.json
```

## Validation signal from the session

Good directory registration used:

```text
path: /root/mgs-agent/data/ares/meta-ads/audit/naming/elena-20260619/
counts: 20 campaigns, 20 adsets, 60 ads, 60 creatives, 60 thumbnails
csv_plan_lines: 61
sha256_manifest: <directory manifest hash>
```

This pattern is reusable for Ares/agente legado/Zeus audit bundles, naming inventories, creative contact sheets, and any generated evidence directory that should remain auditable without flooding chat or causing inventory churn.
