- Multi-manager facts must preserve the source split. Display input lineage/manager attribution and monthly manager results; do not duplicate a site total for every manager. Do not infer a new proportional allocation.
- Use bounded scroll with sticky headers for a long daily grid, so lower expense/manager sections remain reachable. Test 390, 768 and 1440px and actual CRUD, not only successful page loads. Inspect rendered screenshots; grid children need min-width:0 to avoid mobile financial-table overflow.
