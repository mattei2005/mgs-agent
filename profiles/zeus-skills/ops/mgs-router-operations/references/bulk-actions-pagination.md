# Bulk actions and 30-item pagination

Load `docs/mgs-router-bulk-actions-pagination.md` and current receipts for the active UI and runtime behavior. This extends the scoped-groups layout without altering identity/query/DNS/privacy contracts.

- Preserve `action_schema:1`, `group_schema:2`, current revision, both group registries, routes and catalog on every write. A stale/legacy client must fail closed, never reset disabled states silently. Preserve disabled in ordinary editors too.
- Disable traffic by campaign flag or catalog **destination_id**, not by URL equality. Filter only the effective runtime target copy; retain stored URLs/order/weights. Choose among remaining positive weights proportionally; no active target means404/no Location, not an empty redirect or panic. Preserve query/privacy and active legacy500 behavior.
- Scope group activation/deactivation to its member collection. Shared LP identity can affect several campaigns intentionally; equal names in the other group registry are not action targets. Group deletion clears memberships, never deletes members or changes states.
- Protect used LP deletion in both frontend and backend, including combined reference+LP removal in one payload. Block an entire mixed deletion selection instead of partially deleting unused items. Remove references in an earlier revision before deleting the LP.
- Clone campaigns with unique new host/path keys and preserved targets/query; clone LPs with new IDs, not URL deduplication. Group cloning copies that area's members into a distinct group. Start every clone disabled and explain this in the confirmation; never test these mutations on real public records.
- Keep selection keys stable: campaign host + actual newline + path, LP ID, scoped group name. Preserve the literal delimiter in browser/API fixtures; an escaped backslash-n is a different key. Selecting all means only currently rendered rows; prune selection when filter/page removes visibility.
- Render30 campaigns/LPs per page with independent page positions, Anterior/Próxima and X/Y. Reset page1 on search/filter/sort and group-count navigation; clamp after writes. Do not paginate editor destination options or reinterpret group counts as page counts.
- Retain original array indices when filtering/sorting/paginating route editors. Never use a visible-page index to overwrite a different campaign.
- Keep row actions horizontal and compact. Validate relative x/y of real buttons, mobile document width and internal-table scrolling; do not infer density only from CSS source.
- Public QA cancels bulk confirmations and asserts zero route/group POSTs; use the snapshot's actual statuses, not an all-active assumption. Verify first-page min(30,N), empty placeholders, and enumerate every page into a set with exact count/no duplicate equality against API. Test actual clone/delete/enable/disable effects only in isolated state with the real backend.
- Pair code with private state rollback and exact concurrent-state reconciliation. A pre-bulk binary does not honor disabled flags; restoring it alone can reactivate traffic. Single-use executors/receipts must not be repurposed by replacing historical approval IDs.
