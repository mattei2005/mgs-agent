## Complete table and semantics

1. The timeline is paginated (currently 50 rows by default). Enumerate every page, append each batch to an artifact, and validate exact unique `(SEGURADOR,DOMAIN)` membership/count against the native grouped dataset and the paginator's declared total. Never wait for the whole dataset to appear simultaneously in `tbody`.
2. Independently sum native `REVENUE` with Decimal by exact `(PROFILE_NAME,DOMAIN,DATE)`. Preserve absent days as `-`, recorded zero as numeric zero, absent name as `—`, and international characters unchanged. Compare every rendered daily cell and every row/grand total before publication.
3. Explain the grain: SEGURADOR + DOMAIN is a ranking of combinations, not a deduplicated person ranking; one segurador can have multiple lines. Today is partial, and a one-off export is a snapshot rather than an automatic sync.
4. Recheck deployed `TimelineReport.heatClass` before reproducing colors. Current REVENUE rule compares each non-null daily value with the mean of the same row's non-null days: deviation >30% is green, <-30% red, otherwise secondary gray; zero mean is gray. Missing days have normal text. These colors do not signify profit/loss or compare different seguradores. Capture computed foreground colors per cell for exact snapshot fidelity.
