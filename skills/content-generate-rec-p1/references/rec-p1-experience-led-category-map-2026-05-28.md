# REC/P1 experience-led category map — 2026-05-28

## Context

Rodolfo reviewed REC and P1 output for a travel rewards card and identified a scale-level editorial problem: the articles were structurally correct but still read too much like bank/product documentation. Raquel added that the fix must work at scale by adapting category examples into multiple combinations instead of copying fixed example phrases.

## Durable lesson

REC/P1 writing must sell the user's practical experience, not only describe card functions. Each card category has a different routine, emotion, problem and desired feeling. The generator must identify the primary category and any real secondary categories from official/request facts, then translate confirmed features into practical user scenarios.

The silent question every article must answer:

```text
How does this card improve this person's real routine, decision or experience?
```

## Main correction

Avoid writing only about:

- functions;
- rates;
- fees;
- reward categories;
- technical conditions.

Instead connect confirmed facts to:

- routine;
- lifestyle;
- behaviour;
- practical use;
- emotional payoff;
- context of use.

## REC-specific application

REC must be more conversational and conversion-oriented:

- speak directly to `you`, not `the reader`, `users`, or `applicants`;
- open with a real situation or user outcome, not product inventory;
- show how benefits feel in practice;
- vary repeated phrases such as `planned travel`, `partner retailers`, `eligible spend`, `fee-free spending`;
- keep financial responsibility without making the article cold;
- after tables, add strategic interpretation only when it says something card-specific and useful;
- conclude by reinforcing who the card fits and why the value feels practical.

## P1-specific application

P1 must be deeper without becoming technical filler:

- keep 900–1000 words when that is the active bound;
- use compact mobile paragraphs, normally 30–35 words;
- lead with user pain/outcome before APR, fees, or application mechanics;
- create practical scenarios: trips, hotels, overseas spending, subscriptions, repayments, business expenses, etc.;
- reduce repetitive benefit + caution + alert patterns;
- make CTAs inviting but responsible;
- avoid overusing warnings that interrupt conversion momentum.

## Category matrix principle

Each category needs a different dominant experience:

```text
Cashback                  -> smarter everyday spending, routine value back
Travel rewards            -> smoother trips, bookings, overseas spending
Airline                   -> less airport friction, loyalty convenience
Hotel rewards             -> better stays, comfort, check-in/upgrade value
Premium                   -> convenience, time-saving, access without ostentation
Credit builder / secured  -> progress, rebuilding, control without judgment
Balance transfer          -> relief, repayment organisation, lower pressure
Low APR                   -> predictability, budget control
Business / freelancer     -> operational organisation and separation of expenses
Digital bank              -> app-driven simplicity and less bureaucracy
Multi-currency/nomad      -> global mobility and lower international friction
Green/community/Islamic   -> values alignment without moralising or simplification
Crypto/Web3/AI            -> practical digital convenience without hype
```

## Hybrid card rule

Many cards combine categories. Do not force one rigid label. If a card is `cashback + travel`, write about both routine value and travel usefulness. If it is `premium + airline`, connect airport comfort with frequent-flight convenience. If it is `freelancer + multi-currency`, connect work organisation with international flexibility.

Raquel's scale rule: when a confirmed feature fits one or more examples, adapt the approach to create natural variations and multiple combinations. The examples are style references, not reusable copy blocks.

## Hard limits

- Never invent benefits, rates, categories, eligibility, approval odds, limits, insurance, waivers, or perks.
- Do not copy example sentences automatically.
- Do not turn category guidance into hype.
- Do not use negative/judgmental labels for credit builder/secured/student content.
- Do not encourage debt, impulse spending, speculation, or unrealistic savings.
