# REC+P1 global editorial alignment — hard gate (2026-05-26)

## Trigger
Rodolfo clarified that when REC and P1 are created together, quality cannot be checked as two isolated posts. The pair must be planned and validated globally because the REC is the main attention/click driver and the P1 is the supporting conversion page.

## Canonical rule
For any REC+P1 request, Atena must run a global editorial alignment check before considering the package complete.

## Required positioning
- REC = primary attraction and click driver.
- P1 = complementary conversion/support page.
- REC must contain the strongest confirmed benefits, best card information, and clearest value hooks.
- P1 may repeat confirmed benefits when useful, but must expand, explain, and support the REC rather than compete with it or copy it.
- Both pages must use the same official source of truth and remain factually consistent.

## Execution model
REC+P1 is not a third article template. It is an orchestration layer:
1. Extract and rank all confirmed official facts for the card.
2. Assign the highest-impact hooks to the REC.
3. Reserve deeper explanations, conditions, requirements, and application confidence details for the P1.
4. Create the REC with the normal REC template.
5. Create the P1 with the normal P1 template using the REC as origin/context.
6. Validate the pair globally before final reporting.

## Global alignment checklist
Before final summary, verify:
- The REC uses the strongest confirmed benefits and most compelling card information.
- The P1 complements the REC and does not simply duplicate REC sections or wording.
- Claims, fees, APR, benefits, eligibility language, CTA destinations, and image/card identity match across both pages.
- REC CTA points to the P1.
- P1 CTA points to the official issuer URL.
- Both pages maintain their own template requirements, word counts, tags, Yoast fields, and image rules.

## Failure rule
If the REC undersells the strongest confirmed benefits, if the P1 conflicts with or duplicates the REC, or if the pair is not aligned as a funnel, do not report REC+P1 as validated. Repair the mismatch or report the exception clearly.
