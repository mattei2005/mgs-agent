## 🔬 Auto-Crítica — Falha no Método

**Causa raiz:** pré-análise usou `head -10 | grep set`.

Scripts com headers documentais longos (15–27 linhas de comentários) foram flagged falsamente porque o `set -e` aparece *após* o header — fora do range do `head -10`.

**Padrão observado:** scripts mais bem escritos tendem a ter headers documentais mais longos, portanto são *mais* suscetíveis a esse falso positivo. O método penalizava qualidade.

**Correção de método adotada:**
```bash
# ANTES (ruim):
head -10 arquivo.sh | grep "set -e"

# DEPOIS (correto):
grep -n "set -e" arquivo.sh
```
