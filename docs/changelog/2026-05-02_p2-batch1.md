## 🟡 P2 Batch 1 — Logs + 2 Falsos Positivos

### ✅ P2-A — Logs Sem Rotação

**Problema:** zero configs logrotate para mgs/hermes. `monitor-service-restarts.log` em 4.2 MB e crescendo — risco de disk fill em 2–3 meses.

**Fix:** `/etc/logrotate.d/mgs-agent` criado.

| Parâmetro | Valor | Motivo |
|---|---|---|
| Frequência | `daily` | Controle diário |
| Tamanho máximo | `maxsize 10M` | Gatilho emergencial |
| Retenção | `14 dias` | Histórico razoável |
| Modo | `copytruncate` | Apps continuam escrevendo sem restart |
| Compressão | `compress + delaycompress` | Log do dia disponível, histórico comprimido |

**Teste:** rotação forçada gerou `.log.1` para todos os arquivos de log.  
**Automação:** `/etc/cron.daily/logrotate` processa automaticamente.  
**Resultado esperado:** 5 MB+ de logs antigos → ~500 KB comprimidos. Disk fill prevenido permanentemente.
