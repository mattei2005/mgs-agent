# MGS Agent — Convenção de Nomes de Skills

## Padrão
[área]-[verbo]-[objeto]

## Áreas disponíveis
- content   → geração e auditoria de conteúdo
- wp        → WordPress (plugins, manutenção)
- metaads   → Meta Ads (Facebook + Instagram)
- gads      → Google Ads
- finance   → financeiro, sheets, payouts
- chatpion  → disparos no Messenger bot
- monetize  → AdSense, AdX, MonetizeMore

## Verbos comuns
- generate  → criar conteúdo do zero
- audit     → revisar/checar
- publish   → publicar
- pause/resume → controle de campanhas
- clone     → duplicar
- analyze   → analisar performance
- check     → verificações
- update    → atualizar existente
- cleanup   → limpar
- create    → criar (campanhas, etc.)

## Exemplos válidos
- content-generate-rec
- content-audit-broken-links
- wp-cleanup-drafts
- metaads-pause-campaign
- gads-clone-keyword-list

## Exemplos INVÁLIDOS (não usar)
- generateContent (camelCase, errado)
- gera-conteudo (português, manter inglês)
- skill1 (não descritivo)
- meta_create (snake_case, manter kebab-case)
